1. Novel vault Tracker dirancang untuk membantu pengguna mencatat, mengelola, dan memantau progres membaca berbagai buku novel secara terorganisir.

# Fitur utama :
-Mengatur log nove : dapat buat menambah , mengedit , membuang novel yang telah dibuat
-Cover gambar lokal : dapat mengunggah file gambar sendiri
-Pencarian dinamis : mempunyai filter untuk memperlancar pencarian semisal novel yang dipasang sudah banyak
-Layout reponsif : Layout yang dibuat dapat digunakan oleh berbagai jenis perangkat seluler seperti contohya pixel 9 dan ipad mini

# Prasyarat
- Flutter SDK (Versi terbaru)
- Dart SDK
- Android Studio / VS Code

# Langkah-Langkah
1. Clone Repositori & Masuk ke Folder Proyek
2. Buka terminal/command prompt, lalu jalankan perintah berikut secara berurutan:
3. bash
4. git clone <URL_REPOSITORI_GITHUB_KAMU>
